# 错题订正指导 —— 语文 Unit3（2026-10-17）

## 一、写出音节的韵母（第 3 题）

### 1. 原题回顾

| 音节 | 孩子写的 | 正确答案 |
|------|----------|----------|
| jú zi | j（声母） | **ǘ** |
| shù yè | sh（声母） | **ù** |
| gē qǔ | q（声母） | **ǚ** |
| hú xū | h（声母） | **ú** |

### 2. 错因分析

1. **混淆了“声母”和“韵母”**：题目要求写画横线音节的**韵母**，孩子却把音节开头的**声母**填了进去。
2. **韵母概念不牢**：韵母是音节里声母后面的部分，写的时候要**带上声调**。孩子只记住了声母，没意识到“去掉声母，剩下的才是韵母”。
3. **j / q / x 与 ü 的拼写规则没巩固**：像 jú、qǔ，韵母是 **ǘ / ǚ**，不是 u；书写时 ü 上的两点要保留。

### 3. 订正讲解步骤（建议这样说给孩子听）

1. **先读题**：让孩子用手指着“韵母”两个字，说一遍“韵母就是声母后面的部分”。
2. **拆音节**：把每个音节掰成两半：
   - jú = **j** + **ǘ**
   - shù = **sh** + **ù**
   - qǔ = **q** + **ǚ**
   - hú = **h** + **ú**
3. **盖住声母**：让孩子用手遮住前面的 j / sh / q / h，问：“剩下的是什么？”——剩下的就是韵母。
4. **强调声调**：韵母要带上声调帽子，不能写成光秃秃的 u / ü。
5. **特殊提醒**：j、q、x 和 ü 相拼，ü 上两点不省略（写的时候仍写 ü），但读音还是 ü。
6. **让孩子自己讲一遍**：为什么“jú 的韵母是 ǘ，不是 j”。

### 4. 正确订正写法

```
jú 的韵母：ǘ
shù 的韵母：ù
qǔ 的韵母：ǚ
hú 的韵母：ú
```

### 5. 一句话总结给孩子

> 写韵母，先找声母，把它“去掉”，剩下的部分**带上声调**就是韵母；j / q / x 后面跟的是 **ü**，不是 **u**。

## 二、翘舌音（第 4 题）

### 1. 原题回顾

- 标牌一：**小草在生（shēng）长（zhǎng）**——孩子圈了“生、长”，正确。
- 标牌二：**手下留情（shǒu）**——孩子圈了“手”，正确。

### 2. 错因分析

这部分孩子做对了，主要用来**巩固信心**。

### 3. 订正/讲解步骤

1. **复习翘舌音**：zh、ch、sh、r 是翘舌音，舌头要翘起来。
2. **再读标牌**：指着“生、长、手”，说出它们的声母分别是 sh、zh、sh。
3. **注意易混点**：
   - “生”的声母是 **sh**，不是 s；
   - “长”在“生长”里读 **zhǎng**，声母是 **zh**；
   - “手”的声母是 **sh**。
4. **快速检测**：家长随便说几个平舌音 / 翘舌音的字，让孩子判断并用手势（舌头翘不翘）表示。

## 三、动物的房子——思维导图匹配与“还有”拓展（第 3、4 题）

### 1. 原题回顾

**第 3 题（思维导图）：**  
动物：青蛙、虫儿、小鸟、雄鹰  
住所：①池塘 ②山峰 ③草地 ④大树  
孩子答案：青蛙①、虫儿③、小鸟④、雄鹰②，**匹配正确**。

**第 4 题（你还知道谁的房子）：**  
孩子写：**池塘是小鱼的房子。**  
问题在于：直接用了第 3 题选项里已经给出的“池塘”，没有自己再想一个新住所。

### 2. 错因分析

1. **第 3 题匹配本身没错**：孩子对“谁住在哪里”的生活常识是清楚的。
2. **第 4 题错在对“还”的理解**：题目问“你**还**知道谁的房子呢？”，这个“还”是“除了上面这些，**另外/再**说一个”的意思。答案必须是一个题目里**没有出现过的**新动物 + 新房子。孩子却把已经列出来的“池塘”又拿过来用，说明没理解“还”要求“再创新”。
3. **审题习惯没养成**：一看到“池塘、小鱼”搭配合理就写了，没回头看第 3 题已经用过“池塘”。

### 3. 订正讲解步骤（建议这样说给孩子听）

1. **回头看第 3 题已经有哪些家**：指着四个选项说一遍——池塘、山峰、草地、大树。告诉孩子：“这些都是‘旧’的了，第 4 题要再想一个‘新’的。”
2. **解释“还/还有”**：
   - “你还有吗？”就是“除了已经有的，**另外再**来一个”。
   - 例句：我吃了苹果，**还**想吃一个香蕉。（香蕉是新的，不是苹果）
3. **判断孩子的答案**：池塘在第 3 题里已经出现过了，所以不能算“还有”的新答案。小鱼虽然是新动物，但“池塘”这个房子不新。
4. **给几个正确方向**：
   - 大地 → 小草
   - 蜂巢 → 蜜蜂
   - 山洞 → 熊
   - 泥土 → 蚯蚓
5. **让孩子自己挑一个**，工整写一遍，并口头说“为什么这个答案可以”。
6. **举一反三**：让孩子用“还有”造一个生活中的句子，强化“新增、另外”的感觉。

### 4. 正确订正写法

```
大地是小草的房子。
```

其他合理答案：

```
蜂巢是蜜蜂的房子。
山洞是熊的房子。
泥土是蚯蚓的房子。
```

### 5. 一句话总结给孩子

> “**还/还有**”就是“**另外再想一个**”，不能用题目里已经出现过的答案，要找一个新的动物和新的房子。

## 五、看图用拼音补充句子（第 11 题）

### 1. 原题回顾

题目：星期日，小文一家在打扫卫生，小文（图片）在________。  
图片显示：小文在擦窗户/擦玻璃。  
注意：这道题的参考答案图片没有拍到，下面的拼音需要向老师确认后再订正。

### 2. 订正建议

1. **先看图说话**：让孩子说出图片内容，如“小文在擦玻璃”。
2. **写出拼音**：
   - 擦玻璃：**cā bō li**
   - 擦窗户：**cā chuāng hu**
   以老师/课本标准为准。
3. **易错点提醒**：
   - “擦”是平舌音 **cā**，不要读成 chā；
   - “玻”是 **bō**，不要写成 bē；
   - 注意声调标在正确的韵母上。
4. **拿到标准答案后**：让孩子完整抄写一遍，并大声读出来。

### 3. 正确订正写法（待确认）

```
小文在 cā bō li。（若标准答案为“擦玻璃”）
```

或

```
小文在 cā chuāng hu。（若标准答案为“擦窗户”）
```
