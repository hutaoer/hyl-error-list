## 三、巩固题示例

### （一）写韵母（带声调）

写出下面音节的韵母：

1. bō → ______
2. mǎ → ______
3. qǔ → ______
4. nǚ → ______
5. hú → ______
6. chī → ______

**参考答案：** ō、ǎ、ǚ、ǚ、ú、ī

### （二）判断对错

读下面音节，判断韵母写得对不对，不对的请改正。

1. jú 的韵母是 u。（    ）
2. qǔ 的韵母是 ǚ。（    ）
3. hú 的韵母是 h。（    ）
4. shù 的韵母是 ù。（    ）

**参考答案：**
1. 错，应改为 ǘ；2. 对；3. 错，应改为 ú；4. 对。

### （三）圈翘舌音

读句子，圈出声母是 zh / ch / sh / r 的字：

1. 春天，小树苗在生长。
2. 叔叔在山上种树。
3. 日月明，田力男。

**参考答案：**
1. 春（chūn）、生（shēng）、长（zhǎng）
2. 叔（shū）、山（shān）、树（shù）
3. 日（rì）

### （四）仿写句子（注意：不能再用第 3 题的“池塘、山峰、草地、大树”）

用“____是____的房子”写两句，要求写题目里没有出现过的新住所和新动物：

1. ________________ 是 ________________ 的房子。
2. ________________ 是 ________________ 的房子。

**示例答案：**
1. 大地是小草的房子。
2. 蜂巢是蜜蜂的房子。
3. 山洞是熊的房子。

### （五）“还/还有”判断

下面哪些答案符合“还/还有”的要求？在符合的后面打“√”。

题目中已经出现的家：池塘、山峰、草地、大树。

1. 池塘是小鱼的房子。（    ）
2. 山峰是雄鹰的房子。（    ）
3. 大地是小草的房子。（    ）
4. 蜂巢是蜜蜂的房子。（    ）

**参考答案：**
1. 不符合（池塘已经在题目里出现过）；2. 不符合（山峰已经在题目里出现过）；3. 符合；4. 符合。

## 四、家长提示

- 拼音题一定要先让孩子**读准音节**，再动笔；写完后让孩子用手指遮住声母自查：“剩下的是不是韵母？有没有声调？”
- 声调是韵母的一部分，**不要漏掉**。
- j / q / x 后面的 ü，写的时候**保留两点**，读的时候仍读 ü。
- 第 11 题建议向老师确认标准答案后，再让孩子完整写一遍并朗读。
